# Contador de Doações — sem computador

Esta versão não precisa de Node.js, servidor local ou computador.

Ela usa:
- páginas HTML;
- Supabase para armazenamento e sincronização;
- navegador do celular para controle;
- navegador da Smart TV/segundo celular para exibição.

## Configuração única

1. Crie uma conta no Supabase pelo celular.
2. Crie um projeto.
3. Abra o SQL Editor e execute:

```sql
create table contador (
  id bigint generated by default as identity primary key,
  room text unique not null,
  value bigint not null default 0,
  speed integer not null default 900,
  updated_at timestamptz not null default now()
);

alter table contador enable row level security;

create policy "contador_publico_select"
on contador for select using (true);

create policy "contador_publico_insert"
on contador for insert with check (true);

create policy "contador_publico_update"
on contador for update using (true) with check (true);

insert into contador(room,value,speed) values ('principal',0,900);
```

4. Publique estes arquivos em qualquer hospedagem estática que aceite HTML (por exemplo, Netlify ou GitHub Pages).
5. Abra `config.html` pelo celular.
6. Informe o Project URL e a chave pública `anon`.
7. Abra `controle.html` no celular.
8. Abra `tv.html` na Smart TV ou em outro celular.

## Importante

Esta configuração é um protótipo. As políticas acima deixam o contador público para facilitar a instalação. Para um sistema real de arrecadação, coloque autenticação e políticas RLS restritivas antes de usar publicamente.

Não coloque a chave `service_role` no navegador.
